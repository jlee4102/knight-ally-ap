    Wiring up balances

    Standings read a Google Sheet tab directly — no bot, no server, no login. Add a tab with these five columns and the numbers above start filling in.

    Columns: date · member · code · qty · turnout

    member matches the IGN in the roster. code is an event key (—) or an item's Discord channel for a purchase. qty is how many, turnout is the headcount for caves and region kills — leave it blank otherwise.

    One row per credit, void or purchase. The page does the AP arithmetic from the rules file, so the sheet never holds a stale number and the ledger stays an audit trail.

    Rates, prices and rules read live from ap_rules.json. Roster reads live from the 102 Knight Ally loot sheet. Disputes go to officers; the attendance log is the record.
